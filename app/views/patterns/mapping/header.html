Map page header

The header for a full-screen map page: who the user is acting for, stretched to the full width of the screen.

Open this example in a new tab (opens in new tab)

When to use this pattern

Use it on every full-screen map page. The layout includes it for you.

When not to use this pattern

Don't use it on ordinary pages in a fixed-width column. Use the standard header from the main layout there.

How it works

From top to bottom, the header has:

  1. the GOV.UK header (rebranded)
  2. service navigation with the service name
  3. a "Prototype" phase banner
  4. the business sub-header: business name, SBI, the signed-in user's name and a sign out link

Each part goes the full width of the screen, with a 15px gutter that lines up with the sidebar below. The service navigation sits above the map, so its menu isn't hidden behind it on small screens. The GOV.UK header and service navigation are hidden while the map is fullscreen, and the map covers the rest.

The business and user come from session data (myData.businessName, myData.sbi and myData.user.name). If they aren't set, Agile Farm Ltd and Alfred Waldron are shown.

How to build it

The layouts/map-fullscreen.html layout already includes the header. To use it in another layout, include the partial in the header block and set the app-map-page class on <html>, which the header styles depend on.

Variable Use
mapServiceName Service name in the service navigation. Defaults to "Farm and Land Service".
_versionPath Prototype version folder for the sign out link, so it goes to /<version>/sign-out. Defaults to v18/1.2.

Accessibility

  • The business and user names in the sub-header are h3 headings with no h1 or h2 before them, so automated checks report a heading order problem.

Known issues

  • "Farm and Land Service" is a working name, and the service name doesn't link anywhere yet.
  • Between 641px and 1020px wide, the GOV.UK header and service navigation are indented further than the phase banner and sub-header, because GOV.UK's 30px page margin still applies at that width. You can see this in the example above.
