Land data panel

The sidebar of the land summary: totals for the business, a way to find a parcel, and every parcel with its land covers and area.

Open this example in a new tab (opens in new tab)

When to use this pattern

Use it in the sidebar of a full-screen map page that shows all the land parcels on a business.

When not to use this pattern

Don't use it for a single parcel's details. The land parcel panel (land covers, hedges and previous versions) is still being designed, so it isn't part of this library yet.

How it works

Summary

Shows the number of parcels and their total area in hectares, to 4 decimal places.

Find a land parcel

Typing all or part of a parcel ID narrows the list. Matching ignores spaces and case, so "sx3964 78" finds SX3964 7821. The filter only changes the list, not the map. If nothing matches, "No parcels found" is shown and announced.

Selecting a parcel

Selecting a parcel on the map does 3 things:

  • it outlines the parcel on the map
  • it highlights the parcel's row in the list
  • it shows the parcel in a table above the list, so the user doesn't have to scroll to find it

If the filter is hiding that parcel, the filter is cleared. Selecting empty map clears the selection. On a phone, the user selects a parcel with the map component's crosshair and Select button. Done then opens that parcel's page.

Parcel list

There is one row per parcel, with:

  • the parcel ID, which links to the parcel's page
  • every land cover on the parcel, largest area first (a cover type that appears more than once is shown once)
  • the parcel's area

Every column can be sorted (MoJ sortable table).

Data

Parcels and land covers come from the RPA's RPA:LandParcels and RPA:LandCovers WFS services, filtered by SBI. A parcel's ID (ngc) is its SHEET_ID followed by its PARCEL_ID, for example SX39647821. Responses are cached for the browser session.

How to build it

Include the partial in the layout's sidebar, then hand the panel the data. The panel doesn't know about the map: the page tells it when a parcel is selected.

Accessibility

  • The filter's "No parcels found" message and the selected parcel table are live regions, so changes are announced.
  • Selection only goes from the map to the list. Rows look clickable (a pointer cursor and a hover colour), but only the parcel ID link does anything. Keyboard and screen reader users can't select a parcel on the map from the list.
  • "No parcels found" is shown in red bold text, which looks like an error message but isn't one.

Known issues

  • Selecting a row in the list doesn't select the parcel on the map yet.
  • The panel needs live RPA data, so it shows nothing if the WFS services can't be reached.
