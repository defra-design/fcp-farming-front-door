Mapping patterns

Settled building blocks for map pages in the Single front door prototype, for designers and developers.

These patterns are the shared source for the map pages, not just a description of them. The land summary (v1.2 view land) page is built from them, so a change here changes that page too.

Patterns

Full-screen map layout
A sidebar and an interactive map that fill the screen below the header, with a phone layout that opens the map fullscreen.
Map page header
The GOV.UK header, service navigation, phase banner and business sub-header, stretched to the full width of the map layout.
Land data panel
The land summary sidebar: totals, a parcel filter, the selected parcel and a list of every parcel with its land covers and area.

What is not included yet

These are still being designed and tested, so they are not patterns yet:

  • the land parcel data panel (on view-land-parcel): land covers, hedges and previous versions
  • the v1.2 design variants, including the alternative and Countryside Stewardship views, the filter view, the ways of comparing versions (side by side, stacked, overlay, fade, layers, changes) and the dates list

Those pages carry their own copies of the layout code and do not use these shared files.

Where the code lives

File What it is

app/views/_common/map/header.html Map page header
app/views/_common/map/land-data-panel.html Land data panel markup
app/assets/sass/components/_map.scss Styles for all three, scoped to html.app-map-page

Map library

The maps use DEFRA's interactive map component (@defra/interactive-map 0.0.22-alpha) with the MapLibre provider. Land data comes from the Rural Payments Agency's public WFS services (RPA:LandParcels and RPA:LandCovers), filtered by SBI.
